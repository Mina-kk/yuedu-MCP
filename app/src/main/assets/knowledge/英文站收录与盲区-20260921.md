## 3. 各域适配 verdict（反推结论）

| 站点 | 结论 |
|---|---|
| quotev.com / wattpad.com | 优先落地：quotev 纯 DOM 无反爬；wattpad API+HTML 双流成熟 |
| foxaholic.com | WordPress 结构 CSS 明确，但 Cloudflare 防护重，需验 WebView 能否过 |
| comick.dev | 纯 REST JSON API 适合 @js 流；漫画图片站，Legado 阅读支持有限 |
| mangago.me | 目录/元信息可做；章节图片下载在 Legado 成本极高 |
| mangaplus.shueisha.co.jp | **不建议**：Protobuf 二进制 API + 图片 XOR 加密，Legado 原生 JS 无法解析 |
| kisskh | **不建议**：视频 Drama 站，Cloudflare + kkey 双重认证，非文本阅读 |
