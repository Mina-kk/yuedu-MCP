# 方法-图文验证码（searchcode 场景）

> 适用：站点使用图文验证码（如 `searchcode`）进行人机验证。与 Cloudflare 的 JS 挑战不同，这类验证需要用户手动输入验证码图片中的字符。

## 一、核心流程

```
探测 ──→ 交互 ──→ 缓存 ──→ 过期兜底
  ↓        ↓         ↓          ↓
命中     弹图      免重复     自动重弹
searchcode  用户输入   source变量   再次命中时
```

## 二、四环节详解

### 1. 探测 —— 先发空验证码请求

在搜索或正文请求前，先探测是否命中验证码机制。常见触发特征：

- 响应中包含 `searchcode`、`captcha`、`verify` 等关键词
- 状态码 200 但正文被替换为验证码页面
- 接口返回 `{code: -1, msg: "请输入验证码"}` 类结构

```javascript
// 探测是否命中 searchcode
var isVerify = false;
try {
  var body = String(result || '');
  if (body.includes('searchcode') || body.includes('captcha') || body.includes('请输入验证码')) {
    isVerify = true;
  }
  // 部分站点返回 JSON 错误码
  var json = JSON.parse(body);
  if (json.code === -1 || json.code === 1001) {
    isVerify = true;
  }
} catch(e) {}
```

### 2. 交互 —— java.getVerificationCode() 弹图输入

Legado 提供 `java.getVerificationCode(imgUrl)` API，会弹出图片让用户手动输入验证码。

```javascript
function handleVerify() {
  try {
    // 获取验证码图片 URL（从页面中提取）
    var html = String(result || '');
    var imgMatch = html.match(/<img[^>]*src=["']([^"']*captcha[^"']*)["']/i);
    var imgUrl = imgMatch ? imgMatch[1] : '';

    if (!imgUrl) {
      // 备用：尝试从 API 获取验证码图片
      imgUrl = baseUrl + '/captcha?' + Date.now();
    }

    // 弹图让用户输入
    var code = java.getVerificationCode(imgUrl);
    if (!code) {
      java.toast('未输入验证码，请求取消');
      return '';
    }

    return code;
  } catch(e) {
    java.log('验证码处理失败: ' + e);
    return '';
  }
}
```

**关键要点**：

- `java.getVerificationCode(url)` 会**阻塞等待**用户输入
- 用户取消输入时返回空字符串
- 验证码图片 URL 必须是**绝对路径**或可被 Legado 加载的地址
- 部分站点验证码图片需要携带 Cookie，可用 `java.ajax` 先下载再转 data URI
- **验证码图片 URL 必须加时间戳防缓存**：`captcha?t=' + Date.now()`，否则 Legado 或浏览器可能复用旧缓存图片，导致用户输入正确的验证码却验证失败

### 2.5 变量传递 —— searchUrl 与 bookList 的跨规则通信

**关键机制**：`searchUrl` 和 `bookList` 是两个独立的 JS 执行上下文，`key`（搜索关键词）在 `bookList` 中**直接不可用**。必须通过 `java.put / java.get` 跨规则传递。

```javascript
// searchUrl 中缓存搜索关键词
java.put('search_key', key);

// bookList 中读取（用于带验证码重新请求搜索接口）
var sk = java.get('search_key') || '';
```

**典型场景**：

- `searchUrl` 先发空 `code=` 请求触发验证码页面
- `bookList` 检测到 `searchcode` 后，需要重新 POST 带验证码的搜索请求
- 此时 `bookList` 中必须拿到原始 `key`，否则无法重新搜索

**注意**：`java.put / java.get` 是**页面级内存缓存**，当前请求结束后即失效；如需跨请求持久化，用 `source.setVariable / getVariable`。

### 3. 免重复 —— source.setVariable() 缓存 + Cookie Jar

验证码一旦通过，服务端通常会设置 Session Cookie，后续请求自动携带。同时可将验证码存入书源变量，避免短时间内重复弹图。

**简洁方案（单字段直接存取）**：

```javascript
// 直接存验证码字符串（推荐，足够应对大多数场景）
source.setVariable(yzm);

// 读取缓存
var yzco = source.getVariable();
if (yzco && yzco != '') {
    // 有缓存，先尝试用缓存码请求
    result = doPost(yzco);
    if (result.indexOf('searchcode') > -1) {
        // 缓存已过期，重新弹图
        java.longToast('验证码过期，请重新输入');
        yzm = java.getVerificationCode(captchaUrl);
        result = doPost(yzm);
        source.setVariable(yzm);
    }
}
```

**复杂方案（多字段 JSON 对象，需额外存时间戳/Cookie 等）**：

```javascript
// 缓存验证状态
function saveVerifyState(code) {
  try {
    var v = source.getVariable() || '{}';
    var d = JSON.parse(v);
    d.verifyCode = code;
    d.verifyTime = Date.now();
    d.verifyCookie = cookie.getCookie(baseUrl);
    source.setVariable(JSON.stringify(d));
  } catch(e) {}
}

// 读取缓存状态
function loadVerifyState() {
  try {
    var v = source.getVariable() || '{}';
    var d = JSON.parse(v);
    // 5 分钟内不重复弹图（根据站点 TTL 调整）
    if (d.verifyTime && Date.now() - d.verifyTime < 300000) {
      return d.verifyCode || '';
    }
  } catch(e) {}
  return '';
}
```

**配合 enabledCookieJar**：

```json
{
  "enabledCookieJar": true,
  "loginCheckJs": "..."
}
```

开启后 Legado 自动管理 Cookie，验证码通过的 Session 会被持久化，大幅减少重复验证。

### 4. 过期兜底 —— 重新请求时自动重弹

服务端验证码 Session 有有效期，过期后再次请求会重新命中 `searchcode`。需要在关键请求点做兜底检测。

```javascript
@js:
(function(){
  var cached = loadVerifyState();
  var html = String(result || '');

  // 再次命中验证码
  if (html.includes('searchcode') || html.includes('captcha')) {
    var code = handleVerify();
    if (!code) return '';

    // 用验证码重新请求
    var resp = java.ajax(baseUrl + '/search?q=' + encodeURIComponent(key) 
      + '&code=' + encodeURIComponent(code));
    html = String(resp || '');

    // 再次检查是否通过
    if (html.includes('searchcode')) {
      java.toast('验证码错误，请重新输入');
      return '';
    }

    saveVerifyState(code);
    return html;
  }

  return result;
})()
```

## 五、注意事项

1. **不是所有站点都需要**：仅在遇到图文验证码时才添加此逻辑
2. **验证码有效期因站而异**：通常 5~30 分钟，根据实测调整缓存时间
3. **图片路径问题**：相对路径需拼接为绝对地址
4. **用户取消处理**：`getVerificationCode` 返回空时应有降级策略（如跳过、提示）
5. **与 Cloudflare 区分**：图文验证码是**人机识别字符**，Cloudflare 是**JS 挑战/浏览器验证**，两者处理方案不同
6. **验证码图片 URL 必须加时间戳防缓存**，否则用户输对也验证失败
